# Repo Radar

Repo Radar 可以把任意本地代码仓库转换成一份简洁、可交互的项目驾驶舱。它只在本机扫描，最终生成一个独立的 HTML 文件，不会向外发送任何数据。

## 使用方法

在 PowerShell 中运行：

```powershell
.\repo-radar.ps1 C:\你的项目路径 -Open
```

也可以双击 `repo-radar.cmd`，扫描当前文件夹并自动打开报告。你还可以把项目文件夹直接拖到这个 `.cmd` 文件上。

常用参数：

```powershell
# 指定报告保存位置
.\repo-radar.ps1 . -Output .\my-report.html

# 大型仓库可以提高扫描文件数量上限
.\repo-radar.ps1 . -MaxFiles 50000 -Open
```

## 报告包含什么

- 项目类型、语言占比、文件数量、项目大小和 Git 分支
- 自动识别的启动、测试、构建、代码检查和类型检查命令
- README、测试、许可证、持续集成和 Git 工作区状态
- 疑似敏感文件、大文件和扫描范围警告
- 按优先级排列的下一步建议、最近提交、已修改文件和 TODO 标记
- 一键切换英文与简体中文界面

生成的报告是一个自包含的 HTML 文件，可以离线打开。扫描时会自动跳过依赖目录、构建产物、Git 内部文件、虚拟环境和常见缓存目录。

## 隐私与限制

整个扫描过程都在本机完成。生成的报告会包含 TODO 等代码标记所在行的文本，因此请像保管源代码一样保管这份 HTML 报告。

对于环境配置、密钥和证书等疑似敏感文件，Repo Radar 只会记录文件名，不会把文件内容读取到报告中。
